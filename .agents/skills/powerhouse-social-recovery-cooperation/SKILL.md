# Existing Powerhouse agents: delivery recovery cooperation

Fingerprint: `powerhouse|one-brain|social-delivery-recovery-cooperation|v1`.

## Canonical lifecycle

For each blocked daily lane, retain the **same canonical obligation**, existing provider claim, tenant and incident fingerprint. Re-read provider readback before any side effect. In the existing agent fabric route domains `Social`, `Content`, `Integration`, `Reliability` and `Security`, with a single `agent-social-delivery-recovery` coordinator. Specialists may inspect in parallel but must produce a shared evidence-based handoff, never independent post writes:

1. Source intelligence: find independently published, dated, relevant and genuinely different material; an undated article or a re-observed old story cannot count as fresh. If no eligible source exists return truthful `SOURCE_SUPPLY_REQUIRED`.
2. Editorial/quality: verify source lineage, concrete situation → cause → consequence → clear point, real-world personal truth, no fabricated first-person story, and no reuse of a global story-family duplicate.
3. Reliability and security: independently classify retryable technical error vs source exhaustion vs hard OAuth/approval/security boundary. Reject a private Brain/ledger/blog draft crossing public destinations. Require the existing Mira identity threshold `>= 0.940` and original approved final media.
4. Integration: only **one integration writer** handles code/migration changes via the existing protected PR, Required/BRAIN/CodeQL, and exact production parity. No second release owner or hand-edited bypass.
5. Existing canonical channel publisher: use the same original obligation; before send inspect both internal existing-provider records and the authoritative external provider, reserving duplicate claims exactly once. Only after proof may it send the new original content.
6. Provider observer and Brain: require real **provider ID** and **independent readback** before `LIVE_PROVEN`; attach outcome, incident cause, negative replay, regression test and preventive skill update to canonical Brain/Heartbeat.

## Bounded no-stall recovery

A failed attempt must produce a *different* validated source or a tested implementation revision. Never rerun identical rejected source/provider API, clear a duplicate reservation, re-label source freshness, invent a video, downgrade a gate, spend unbounded API quota, or set status green without proof. Genuine OAuth consent, quality or **security boundary** means a specific action waits for independent authorization, not shutdown of the existing daily executor. Other independent lanes continue. No new scheduler, publisher, queue, external Make/Buffer execution, or fabricated event. The existing canonical publisher is solely responsible for posting.
