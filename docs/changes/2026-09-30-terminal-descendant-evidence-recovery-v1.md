# Terminal descendant evidence recovery v1

Terminal delivery is now monotonic under concurrent main movement.

If an exact merge Brain foundation run is cancelled or skipped by a newer protected main, closure may use a successful current-main Brain foundation only after proving the original merge is an ancestor of that main. Genuine failed gates remain fail-closed.

The obligation terminalizer now passes lineage mode directly into the same process and refuses LIVE_BEWEZEN if merged lineage verification is false.
