# Static i18n growth-loop cache recovery

De productiebuild vereiste negen Engelse cachevertalingen voor nieuwe Nederlandse growth-loopcopy. Deze zijn deterministisch toegevoegd via een cachepatch zodat productie zonder netwerkvertaling kan bouwen.

Preventie: nieuwe publieke Nederlandse copy en de bijbehorende statische Engelse cache-entry worden voortaan in dezelfde delivery-lineage toegevoegd.
