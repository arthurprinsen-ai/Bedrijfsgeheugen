# Original social Posts → daily SEO/AI/website source → ONE BRAIN → Heartbeat

12 November 2026. Follow-up after protected and live [PR #5660](https://github.com/arthurprinsen-ai/Bedrijfsgeheugen/pull/5660). Existing original #175 (source archive) and #140 (BRAIN/Heartbeat consumer) already independently share an exact SHA256 per-day source manifest and accept source revisions. Original posts and their metrics still were not represented as a distinct daily source; a generic LinkedIn/Instagram snapshot count alone did not preserve live publication and engagement readback.

**Original identity trap:** LinkedIn personal `social_posts.tenant_id='canonical'`, company `social_posts.tenant_id='bedrijfsgeheugen'`. Both are the two original first-party source owners; never include other customer tenants. On 12 November two original LinkedIn posts were live/proven and Instagram remained PLANNED; zero post-specific authenticated numeric observations existed for the 12-Nov posts at the audited instant. On 11 November both LinkedIn posts were live/proven, Instagram FAILED; one post had source-linked numeric provider observations. An authentically observed Windsor metric for another date is NOT a current 24h/48h/72h snapshot for a newer post.

**Safe permanent extension:** The eighth `posts_publication_and_metrics` original daily source class joins the originals `content_publication_obligations`, `social_posts`, `social_metric_snapshots`, with stable producer revision hashed from original per-post IDs, published proof timestamps, status, and real provider metrics. It separates original post obligations from LIVE_PROVEN receipts, original social post registration, source-linked observed numeric metric coverage, and unverified/failed/pending posts. It cannot invent engagement when an API returned no numeric linked metrics.

The existing #175 automatically writes this eighth class in its original day/tenant manifest. The same existing #140 consumer independently rechecks the full revised SHA256 and stores post counts plus `COLLECT_SOURCE_LINKED_PROVIDER_POST_METRICS` or a non-executed reversible hook/CTA holdout **candidate**. Original Heartbeat reads the #140 ACK through the existing event; no second task or scheduler. Any missing fields remain visible, with original owner and next action. True experiment winners, incremental lift, revenue and historic provider windows need separate independent results. Existing original security, cron and OAuth boundaries unchanged.
