# Pricing lifecycle segmentation v1

The pricing page now starts from the buyer's actual business situation instead of only package size.

Added lifecycle routes:
- growth and professionalisation;
- loss and recovery;
- acute continuity pressure;
- buy-side M&A;
- sell-side / exit readiness;
- investor / portfolio oversight.

Each route exposes a first step, execution option, ongoing control where relevant, indicative pricing, and the analytical models used. The existing Scan → Build → Run → Grow commercial model remains intact underneath.

The pricing calculator now also takes business situation and urgency into account. Distress messaging explicitly states that Bedrijfsgeheugen provides business analysis, data, scenario and execution support and that formal insolvency/legal work requires qualified specialists.
