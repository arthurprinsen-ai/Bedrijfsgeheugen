# Wet DBA static i18n cache recovery

The 3 October 2026 daily Wet DBA article introduced new Dutch public copy without the deterministic English cache entries required by the static locale build.

The recovery now closes both layers exposed by the protected pipeline: **66 source-copy strings** plus **8 additional strings generated by later SEO/build transforms**. Both are supplied through the existing append-only `config/bg-static-i18n-en.d` mechanism.

This is intentionally separate from the Platform-navigation obligation because it restores the shared website delivery baseline. The executable historical replay covers both incident sets, while exact Netlify build parity remains the terminal fail-closed authority.
