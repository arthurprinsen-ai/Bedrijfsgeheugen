# 2026-10-05 — Human commercial message loop

Powerhouse now treats sales technique, ethical persuasion, copy quality and business outcomes as one canonical commercial lineage instead of separate documentation and runtime concerns.

The runtime selects a sales play from context and buying state, applies the canonical persuasion authority, generates channel-native copy, validates exact message quality, blocks email/LinkedIn-DM execution without a passed message hash, carries the same message intelligence into sales outcomes and learns strategy performance only from observed business outcomes and realized revenue.

Canonical lineage:

`observe → understand → predict → value/problem → strategy/play/psychology → message/quality → NBA/channel → provider → outcome/revenue → attribution → calibration/learning → next decision`

Key protections:
- no generic opening or invented trigger;
- internal taxonomy/snake_case may not become prospect-facing personalization;
- a trigger play requires human-readable source context and semantic source match;
- directories are not treated as buying-trigger evidence;
- one primary problem and at most one CTA;
- no reply guilt, fake urgency, hard-close or unsupported numeric claims;
- outbound email/LinkedIn DM requires an exact passed message hash at both executor and database boundary;
- sent/delivered/queued are not counted as business outcomes for strategy promotion;
- sales-play learning remains hypothesis/active until sufficient observed outcomes exist.
