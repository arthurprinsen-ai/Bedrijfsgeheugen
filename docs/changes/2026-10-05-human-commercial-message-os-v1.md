# Human Commercial Message OS v1 — 5 October 2026

Powerhouse now treats sales knowledge, copy psychology, public research, channel choice and outcome learning as one canonical runtime path.

## Closed loop

Public/relationship evidence → semantic relevance → sales play → psychology → human copy → deterministic quality gate → Gmail/SalesRobot executor → provider readback → sales outcome/revenue → technique performance learning.

## Runtime rules

- Trigger outreach requires human-readable public evidence and semantic source-to-trigger relevance.
- Recruitment/talent acquisition is not M&A evidence.
- Supplier/directory pages are not AI buying-trigger evidence.
- Predicted objections never become observed objections by self-reference.
- Machine taxonomy, snake_case and internal scores cannot be used as prospect-facing personalization.
- Gmail and LinkedIn DM fail closed when message strategy or composer quality proof is absent.
- Existing pressure, suppression, provider-readback, dedupe and human-approval gates remain authoritative.
- Copy performance is measured by channel, sales play, psychology, CTA, positive outcome and realized revenue.

## Knowledge sources consolidated

Existing Notion sources remain knowledge authority for SPIN, Challenger, trigger outreach, commitment close, objection handling, reciprocity, reactance reduction, loss awareness, mere exposure, category-entry moments, tone of voice and channel formulas. This change moves those principles into runtime decision labels and learning instead of leaving them as documentation only.
