## Same system; no new executor
`brain/observability/planned-action-review-queue.mjs` compiles validated real actions from the **existing** BRAIN records into a privacy-safe queue with timestamp, original agent, source run URL, exact source SHA, observed matched/blocked rule IDs, keyed action digest and suggested evidence file path. It rejects conflicting observations, missing source proof, malformed records and cross-tenant records; it does not invent labels.

`scripts/brain/planned-action-review-audit.mjs` uses **only read-only** GETs against the existing authenticated `public.brain_records` API on `*.supabase.co`. It does not create a table, schedule, cron, provider, workflow or reviewer identity. The original existing `.github/workflows/whole-brain-canonical-loop-v2.yml` scheduled run performs this audit only on protected `refs/heads/main`, persists the review-queue **artifact of that existing GitHub run**, and gives summary counts and `NOT_MEASURED` until provider-approved labels exist. Existing main-only secret routing is unchanged. Missing authentication or invalid provider responses fail the audit and write a failure evidence artifact, never a fictitious green.

## External independent reviewer approval contract
The observer's own `verified` or `independent` flags cannot establish label correctness. An independent reviewer must inspect the **actual original source at the captured SHA** and PROVEN prevention-rule roots; reconstruct the exact action (not merely its HMAC), confirm which rules apply, and commit exactly one file:
`brain/independent-reviews/<decisionRecordId>.json`
in a GitHub PR that adds **only this file**. It contains:
`contract: "PLANNED_ACTION_INDEPENDENT_REVIEW_V1"`, `decisionRecordId`, `reviewerId: "github:<reviewer_login>"`, `sourceRef`, `sourceRevision`, `actionHmacSha256`, `expectedRuleIds`, `evidenceRef: "https://github.com/arthurprinsen-ai/Bedrijfsgeheugen/pull/<actual-review-pr>"`. No raw action text, prompt, token or user data. A different GitHub identity (not the PR author or original agent) must explicitly **APPROVE that exact PR head commit**. The protected PR must merge, and only the exact main-merged file can serve as proof.

After this external source-grounded approval, an **existing authorized BRAIN writer** can append the corresponding independent `Verification/verification` record with `verified=true`, `independent=true`, that reviewer ID, `decisionRecordId`, `expectedRuleIds` and `evidenceRef`. These self-reported flags **alone are not proof**. The evaluator independently asks GitHub for merged PR details, exact-head APPROVED reviewer events, file path + content and cross-checks the BRAIN record. A false or unverified attestation is excluded. The legitimate reviewer can be a different authorized human or an independently governed reviewer agent with a distinct GitHub identity, but **never the originating agent self-labeling**.

## Rates and closure
Only the original `evaluatePlannedActionRecall` calculates TP, FN, FP, false-block rate from verified labels. Minimum support remains **30 genuine reviewed decisions across at least 2 agents, with >=10 independently positive and >=10 independently safe negatives**. If none exist, `NOT_MEASURED` with null metrics; underfilled corpus `INSUFFICIENT_EVIDENCE` with null rates. A passing CI workflow, 2 benign source actions, or high raw event volume can never become 100% recall. Source mismatch, PR-review absence, arbitrary artifact or missing independent decision is excluded. No causal prevented-incident claim without actual independently verified outcomes.
