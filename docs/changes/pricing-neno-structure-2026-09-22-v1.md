# Pricing page: clearer package selection and estimator

The pricing page now presents Scan, Control, Scale and Enterprise as clearer decision cards, including explicit fit criteria, monthly/yearly presentation and an interactive package estimator based on company size, source count and required refresh cadence.

The existing detailed comparison, FAQ and commercial flow remain available below the new decision layer. During release validation a separate support blog exposed a performance and evidence-contract issue; that page was repaired only as far as required to satisfy the shared release contracts.

## Prevention

Future material website changes must carry Brain learning, a development-ledger event and human-readable change documentation in the same candidate. Touched static blog pages should not depend on non-essential third-party runtime requests when they are subject to the Lighthouse performance gate.
