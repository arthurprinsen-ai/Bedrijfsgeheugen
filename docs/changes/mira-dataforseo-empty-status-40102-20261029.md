# Treat empty Google News results as empty, not as publisher failures

The existing Mira source radar uses a bounded eight-query news search. DataForSEO can return an HTTP-successful task whose status is 40102, meaning the search produced no results. The radar already handled another no-results status (40101) as empty, but logged 40102 as a recoverable provider fault. This change extends the strict empty-response classifier to both codes and adds executable positive and negative tests. Other failures still fail closed. No extra searches or hidden retries are introduced, and a successful search with zero articles cannot create a publishable story. The existing source dating, problem relevance, deduplication, quality and identity rules remain unchanged. It must still collect genuinely dated original evidence before any video can be created or published.
