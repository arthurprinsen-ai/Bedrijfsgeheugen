# Source-backed all-channel loop v1

Fingerprint: `powerhouse-source-backed-all-channels-v1`.

Powerhouse uses one evidence-first loop across Instagram, LinkedIn personal, LinkedIn company, blog, email and LinkedIn DM:

`SOURCE -> EVIDENCE -> DEDUPE -> PROBLEM/TRIGGER -> CHANNEL FIT -> CANDIDATE -> IDENTITY/TRUTH GATE -> PUBLISH/SEND -> PROVIDER READBACK -> OUTCOME -> LEARNING -> NEXT SELECTION`.

Channel identity remains separate:
- LinkedIn personal: public signals may choose the topic, but first-person claims require verified Arthur truth. Never invent that Arthur experienced a public complaint.
- LinkedIn company: current MKB/CEO/MT problem evidence, entrepreneur language, business impact and a relevant Powerhouse capability.
- Blog: same evidence spine plus search/commercial intent; update an owned canonical page before creating cannibalizing content.
- Email: account/person-specific trigger + relationship context + suppression/reply learning. No generic mass personalization.
- LinkedIn DM: account-specific trigger + relationship context + micro-CTA. No bulk generic DM and no fabricated relationship.
- Instagram: public private-life friction, Mira-only, no forced business bridge.

Static calendars are fallback only when no fresh eligible evidence-backed candidate exists. Every outbound side effect must retain source lineage and write replies, engagement, leads, orders and revenue back into Powerhouse learning.
