# Risk-scoped website browser verification

Website browser verification is proportional to release risk without weakening the public-visibility safety baseline. Public pages remain subject to the mandatory visibility check. Full header-menu readability and broad browser regression remain reserved for high-risk changes, while bounded normal-risk changes use targeted desktop/mobile affected-route verification.

Regulatory data changes map to `/`, `/ai-act`, `/compliance-status`, `/benchmark` and `/monitor`, so affected-route checks cover the relevant public surfaces without an unrelated broad menu/regression sweep.
