# Hero-film: drone-vlucht terug

Arthur wil het oorspronkelijke filmpje terug: een rustige drone-vlucht door architectuur, overzicht als een vogel. De vervanging (vrouw met kaartje) is verwijderd. Het bestaande hero-filmpje (hero-shanghai-v2.mp4) vult weer de hele hero op desktop en staat als band bovenaan op mobiel. Links vervaagt het beeld in het papier zodat de tekst leesbaar blijft. Kop blijft hoog (h1 304 px op 390x844). Cache-bust CSS `?v=20261118n`, JS `?v=20261118m`.
