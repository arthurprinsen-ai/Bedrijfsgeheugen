# Governance-only terminal Brain evidence

A governance/control-plane merge can be safely contained in a newer main while its merge-SHA Brain Foundation run is cancelled by latest-main concurrency. Terminal closure now treats that as supersession, not a reason to hang or fail indefinitely.

For governance-only changes, exact-head Required and CodeQL remain required. Brain evidence may come from a successful Whole Brain Canonical Loop v2 or Powerhouse Skill Projection push run for the exact merge SHA, together with proof that the merge SHA is an ancestor of current main. Runtime-affecting changes retain the existing stricter path.
