# CMS selector helper repair\n\nDe CMS-admin gebruikte per ongeluk twee keer dezelfde `$`-helper: eerst voor `querySelector`, daarna voor `querySelectorAll`. Daardoor ontving de event-binder een array en crashte `/cms` met `addEventListener is not a function`.\n\nHerstel: `$` blijft de single-element selector; `all` is de collection-selector. De volledige paginadiagnose blijft `/cms` bewaken.\n
