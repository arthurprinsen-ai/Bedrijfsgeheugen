# Afmelden via antwoord op proefmails

- De dagelijkse run kijkt eerst in de mailbox naar antwoorden van proefklanten die de afgelopen 14 dagen een mail kregen. Een antwoord met "afmelden" of "uitschrijven" zet het adres op de blokkadelijst; daarna gaat er geen mail meer naar dat adres.
- Geciteerde regels (die met ">") en de eigen afmeldregel tellen niet mee.
