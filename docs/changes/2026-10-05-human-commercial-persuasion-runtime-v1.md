# Human commercial persuasion runtime v1

Powerhouse now treats sales technique, persuasion, message structure, evidence, tone, objection handling and channel execution as one runtime chain.

Canonical flow:

signal / relationship context → sales action → existing persuasion optimizer → channel sales play → human commercial composer → deterministic quality gate → executor → provider acknowledgement → outcome / revenue → persuasion performance learning.

The existing `powerhouse_persuasion_revenue_optimizer_v1` remains the psychology authority. The sales playbook only controls channel form, message structure and limits. It does not create a second persuasion truth.

Hard guards include: evidence specificity, no fabricated facts or numbers, no fake scarcity, no guilt follow-ups, no sensitive-trait profiling, one primary problem, one CTA maximum and no send without a current quality pass.

Production readback on 2026-10-05 showed 17 pending commercial actions, all 17 strategy-labeled and persuasion-labeled; 15 already had quality-passed drafts.

## Composer v2 hardening

The canonical composer now requires personalization to resolve to readable, source-specific prospect evidence. Empty compliments, unsupported broad claims such as “many companies…”, and persona-style statements inferred from role alone are blocked. Gmail and SalesRobot require the current `powerhouse-human-commercial-message-composer-v2` proof before provider execution, so stale v1-approved copy cannot pass the execution boundary.
