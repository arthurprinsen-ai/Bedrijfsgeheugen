# Autonomous Engineering Fabric v3

Gebouwd voor snellere ontwikkeling met meerdere chats en agents, zonder extra delivery-authority.

Toegevoegd:
- R0-R4 risk-classificatie;
- outcome-aware agent routing;
- bounded parallel work packages;
- één Integration Agent als candidate-writer;
- late-bound closure manifest;
- dagelijkse bounded tuning vanuit CI Intelligence;
- protected auto-PR voor tuning;
- nieuwe integration- en code-quality agents;
- Required- en Daily Self Evolution-gates.

Safety: Required, security, exact-SHA, protected merge en production readback blijven fail-closed.
