# Powerhouse Manual LinkedIn DM Handoff v1

Powerhouse now owns everything up to the one LinkedIn action that cannot be executed by the connected provider.

The Arthur Actions surface shows only manual work. A DM card contains the recipient, role, company, relationship state, why-now signal, estimated value, final message text and any required attachment. If the selected Give/Get asset is PDF-class, Powerhouse generates the PDF itself and the user downloads that finished document from the card.

The user only needs to open the LinkedIn profile, paste the supplied message, add the supplied PDF when present and press Send. Pressing “Sent” in the cockpit writes the execution outcome back into the canonical commercial learning loop. “Later” and “Not relevant” feed the same loop and prevent repeated blind outreach.

Unknown connection data is shown as unverified rather than inferred.
