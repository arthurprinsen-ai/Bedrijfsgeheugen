# Centrale CMS- en taalwissel

De publieke website gebruikt één centrale site-shell voor header, footer, mega-menu, navigatie en taalkeuze. De NL/EN-keuze verwijst voortaan naar de vooraf gebouwde taalvariant van exact dezelfde route. Daardoor wordt taalwisselen onderdeel van dezelfde centrale website-authority in plaats van losse JavaScript- of pagina-oplossingen.

De portal/dynamische context mag runtime vertaling blijven gebruiken; de publieke website niet.
