# Customer evidence review portfolio for AI, privacy, cost and CSRD

The existing tenant Data Sovereignty page shows the bounded evidence task list from `snapshot.reviewPortfolio` returned by backend #4184. For each pending task, it explains what must be checked and states that evidence is not yet verified. Candidate ESRS standards are not assumed to apply to the customer's organization. Values are HTML-escaped and raw provenance metadata is not rendered.

This is a view in the existing customer compliance page, not a second dashboard, legal approval, new provider runtime, emissions measurement or automated completion.
