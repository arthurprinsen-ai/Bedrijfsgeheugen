# Security Trust Center v1

Data & AI-soevereiniteit en security worden één Trust & Governance-ervaring. Klanten beginnen bij concrete vragen en kunnen doorklikken naar evidence.

De bestaande sovereignty control plane blijft de bron voor dataflows, opslag, verwerking, AI-routes en cross-border truth. De securitylaag voegt append-only provider/IAM observations, freshness/expiry, live PostgreSQL catalog posture, frameworks en open findings toe.

Er komt geen tweede scheduler: public.powerhouse_refresh_data_sovereignty_v1() ververst ook refresh_security_trust_snapshot_v1(). Truth: measured_or_evidence_backed_else_unknown. Provider assurance is nooit automatisch Bedrijfsgeheugen-certificering.
