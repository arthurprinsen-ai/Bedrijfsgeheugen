# Contextual foresight in Portal V2

Foresight is no longer treated as a separate intelligence destination. Portal V2 now projects it into the decision context where it matters.

The executive overview shows what Powerhouse expects to happen next when sufficient observed history exists. Businesscase, financing, due diligence and exit pages show the forecast next to what-if scenarios. Roadmap and active-action pages show the same predictive context alongside the action path. Trust, Brain, Outcomes and Learning surfaces show prediction-quality evidence such as Brier score, calibration error and timing error.

When evidence is insufficient, the portal explicitly shows that state instead of creating an illustrative prediction.
