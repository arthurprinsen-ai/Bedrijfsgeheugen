# Mira public-problem source loop v1

Canonical Instagram/Mira lineage:

`public blogs/forums/consumer complaints -> powerhouse_mira_problem_signals_v1 -> score/dedupe -> powerhouse_content_recommendations -> powerhouse_instagram_daily_winners_v1 -> OpenArt Mira Reel -> powerhouse-social-publisher -> provider readback -> social_posts/social_metric_snapshots -> powerhouse_mira_problem_lineage_v1 -> winner outcome_evidence -> next ranking`.

## Rules
- Mira remains private/daily-life/human; no forced Bedrijfsgeheugen business moral.
- Inputs are current public evidence such as blogs, Reddit/forum discussions, Tweakers, Radar and Kassa-style complaint pages.
- Static calendar seeds are fallback only. A fresh source-backed eligible recommendation ranks first.
- One source/topic may not be reused within 45 days by this loop.
- The daily winner stays immutable after selection.
- Metrics and learning write back to the exact source/recommendation/winner lineage.
- The collector runs every six hours for the next Europe/Amsterdam publication date; outcome reconciliation runs hourly.
