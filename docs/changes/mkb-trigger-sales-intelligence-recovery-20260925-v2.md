# MKB trigger sales intelligence — recovery op current main

De oorspronkelijke implementatie uit #2712 bevatte unieke commerciële intelligence maar stond op een sterk verouderde branch. De recovery in #2874 replayt die wijzigingen conflictvrij op current main, zonder latere main-wijzigingen terug te draaien.
