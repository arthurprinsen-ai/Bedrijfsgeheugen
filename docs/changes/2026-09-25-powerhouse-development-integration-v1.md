# Whole Brain development integration

Powerhouse is one connected operating system. A feature, bug fix, connector, data source, workflow, agent, skill, website change or Portal V2 change therefore cannot be delivered as an isolated technical change.

## What changes for every agent and chat

Before material implementation, the execution node reads current state, the System Map, open obligations and relevant learning/skills. It reuses existing authorities and capabilities first and performs a Brain impact analysis across evidence, knowledge, graph relations, semantics, signals, prediction, impact/value, decision intelligence, agents, delivery, learning, governance and resource/sustainability.

## Portal rule

When new or changed intelligence matters to a customer, directie/MT or operator, it must become contextually available in the existing Portal V2 or cockpit. Portal UI remains a projection of canonical runtime truth and is never a separate authority.

If no portal surface is appropriate, the change must explicitly record `NO_PORTAL_SURFACE` with a concrete reason.

## System Map rule

A create, rename, retire or rewire of a material capability must be registered in the canonical System Map with its identity, owner, inputs, outputs and relations. Read-after-write is required before terminal completion.

## Learning and skills

Reusable capability knowledge, root causes, failed approaches and prevention rules are written to canonical Brain learning. Skills are derived execution projections. Deterministic skill projection must be current so subsequent chats and agents automatically consume the new behavior.

## Definition of Done

A local implementation, commit, PR or deploy is not terminal. Completion requires the applicable local and cross-Powerhouse regressions, System Map readback, Portal readback or explicit no-surface rationale, protected delivery, production/provider readback, outcome/value evidence, learning/prevention writeback and skill projection readback.

Canonical fingerprint: `development|whole-brain-portal-skill-integration|v1`.
