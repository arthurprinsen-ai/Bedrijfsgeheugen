Geen extra Tavily/DataForSEO-kosten/calls, geen nieuwe bronproducent, cron, scheduler, mediajob, asset of publisher. Nieuwe formulering is géén publicatievergunning.

## Go-live-grens
Source en tests gaan via Required/CodeQL/protected-main. De wijziging blijft volledig binnen de oorspronkelijke Radar-directory, zodat de bestaande Edge-releasecontrole niet alle Supabase Edge Functions hoeft te reattesteren. Voor Supabase Edge verbiedt `AGENTS.md` directe chatdeploy. Alleen de originele Supabase GitHub Integration vanaf protected `main` mag de nieuwe shared helper naar de originele radar uitrollen. Pas na onafhankelijke provider-versie/readback en natuurlijke #120 bronquery met uniek geverifieerd resultaat kan de bronaanvoer als hersteld gelden. Zonder dat blijft de post OPEN.
