# CI Pattern Memory v1

CI Pattern Memory complements Delivery Pattern Memory.

Delivery Pattern Memory selects proven regressions from canonical Brain learning. CI Pattern Memory learns empirical hot files and recurring workflow/job failure signatures from a rolling 30-day GitHub Actions window.

A file becomes hot only after repeated association with failed pull requests. One-off failures are not promoted into policy. The latest successful CI pattern-memory artifact is restored by Required test and supplied to the Integration Bundle Compiler. Hot-file evidence may raise adaptive risk by one class; it can never lower static, security or production risk.

If the artifact is unavailable, delivery safely falls back to Adaptive Delivery plus canonical Brain Delivery Pattern Memory.
