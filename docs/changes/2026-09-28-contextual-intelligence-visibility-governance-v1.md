# Contextual intelligence visibility is now a Powerhouse-wide rule

The contextual foresight implementation is generalized into a permanent Powerhouse governance rule.

From now on, a material intelligence capability is not considered complete if it can influence a management decision but remains visible only in backend runtime, logs, Brain or a standalone technical screen. It must be projected into the relevant Portal V2 context with the right visual form, evidence state and uncertainty.

This rule is now recorded in Company Intelligence OS, System Map Governance and the canonical System Map.

The learning record is compiler-canonicalized so the prevention rule can be projected into the relevant Powerhouse skills automatically.
