# Material writeback closure — mandatory for agents and chats

Repository-backed Powerhouse work can no longer rely on an instruction such as “borg, log en documenteer” alone.

For every material candidate, Required CI verifies that the candidate itself contains a complete closure bundle: canonical Brain learning, an append-only activity/development-ledger event, and human-readable change or learning documentation.

If any evidence class is missing, the candidate fails before expensive delivery lanes start. Automatic learning → skill projection remains downstream authority for propagating reusable prevention rules into agent/chat skill context. Post-merge terminal closure still requires production readback, outcome evidence, projection readback and durable control-plane evidence.

Fingerprint: `powerhouse|material-run|closure-artifacts|required|v1`.
