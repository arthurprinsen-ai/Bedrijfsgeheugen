# Hero mobiel: korte versie

Arthur stuurde een schermafbeelding van de mobiele hero en vond het veel tekst. De hero-kolom was 994 px hoog (lange uitleg, geruststelling, downloadlink, bronregel, rekenvoorbeeld). Op schermen tot 860 px blijven nu kop, belofte, hoofdknop, link naar het portaal, "Neem je moment" en één zin geruststelling ("Geen formulier. Geen e-mail. Geen verplichting. Meteen resultaat."). Hero-kolom 442 px NL, 485 px EN op 390x844. Desktop ongewijzigd. De lange uitleg blijft in de pagina verderop beschikbaar. Cache-bust CSS `?v=20261118p`, JS `?v=20261118o`.
