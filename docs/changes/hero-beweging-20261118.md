# Hero-beeld krijgt rustige beweging

De besluitkaart (voorbeeld) vult zich nu in een lus van 16 seconden: titel, waarom nu, bron, eigenaar, vastgelegd, met één zachte lichtpuls bij het label. Daarna verschijnt een gestippelde kaart "Vorige maand · zonder bron": wat verdwijnt als een besluit niet wordt vastgelegd. Dat is de eerlijke verliesvorm van FOMO; geen teller, deadline of schaarste. Uit bij `prefers-reduced-motion`. Alleen CSS-animatie en een extra element, geen video, dus geen laadtijd. Cache-bust CSS `?v=20261118l`, JS `?v=20261118k`.
Niet bewezen: live-readback tot na merge; effect op vertrouwen of kliks (meten via bg_interacties). Mensen in beeld ontbreken nog.
