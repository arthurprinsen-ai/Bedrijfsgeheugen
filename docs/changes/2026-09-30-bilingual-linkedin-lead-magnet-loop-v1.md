# Bilingual LinkedIn lead-magnet loop v1

Date: 2026-09-30

## Decision
Bedrijfsgeheugen uses one language per LinkedIn post. High-utility value assets can have separate NL and EN editions. A translation is never a new semantic story for duplicate-gate purposes.

## Closed loop
research/signal -> useful asset -> LinkedIn post -> comment keyword -> DM delivery -> relationship enrichment -> qualified follow-up -> meeting/proposal/order -> realized revenue -> learning.

## Initial asset portfolio
1. 100 manual tasks to stop doing manually (`100`)
2. 50 AI automations for SMEs (`50`)
3. 25 predictions for AI/work/SMEs (`2027`)
4. AI ROI Calculator (`ROI`)
5. AI Stack by Department (`STACK`)
6. AI Governance Starter Kit (`SAFE`)
7. Knowledge Loss Risk Map (`RISK`)

## Guardrails
Composio is the LinkedIn publication authority. Buffer and Make are not LinkedIn fallbacks. Global semantic duplicate prevention remains mandatory. Prediction assets are directional and sourced.
