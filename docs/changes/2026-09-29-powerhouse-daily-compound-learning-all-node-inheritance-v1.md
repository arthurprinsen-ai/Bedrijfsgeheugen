# Powerhouse Daily Compound Learning — all-node borging

Datum: 2026-09-29

## Besluit

Daily Compound Learning is niet alleen een runtime-functie maar een permanente ONE BRAIN-invariant voor alle huidige en toekomstige chats, agents, skills, workflows, schedulers en autonome capabilities.

## Verplichte keten

`observe → context → decide → execute → readback → verified outcome → Outcome Memory → forecast resolution/calibration → learn → next decision`

## Borging

- `AGENTS.md` maakt de regel bindend voor iedere execution node.
- `config/brain-chat-learning-contract.json` maakt de learning onderdeel van iedere materiële chat/agent-preflight.
- Continuity, Company Intelligence OS, Foresight, Self-Improvement en System Map Governance erven exact dezelfde fingerprint.
- De canonieke System Map koppelt de runtime expliciet aan agent contract, chat-learning contract en continuity skill.
- Een regressietest controleert dat deze inheritance-links niet kunnen verdwijnen zonder CI-fout.

## Truth boundary

Alleen geverifieerde geobserveerde outcomes mogen learning voeden. Stilte, transport-success, HTTP 2xx, commits, merges, deploy-starts, forecasts, smoke-tests of synthetische events zijn geen realized outcome. Geen parallel outcome-, forecast- of learningstore is toegestaan.

## Definition of Done

Materieel Powerhouse-werk eindigt pas na uitvoering, provider/production readback, verified outcome/value waar beschikbaar, learning/prevention, skill projection en next-agent discoverability via de System Map/shared learning context.
