# Canonical redirects voor branchepagina's — 25 september 2026

De branche-landingspagina's gebruiken extensionless canonicals. Deze recovery voegt permanente 301-redirects toe van legacy `.html`-varianten naar dezelfde extensionless routes.

Preventieregel: nieuwe root-level branchepagina's krijgen tegelijk met hun canonical route een legacy `.html` redirect, zodat sitemap, canonical en oude inkomende links op één URL-truth uitkomen.
