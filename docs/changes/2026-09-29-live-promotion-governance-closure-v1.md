# Powerhouse live-promotion governance closure — 29 september 2026

## Permanente standaard

Een opdracht als **“zet live”** eindigt niet bij een deploy, merge of provider-status. De canonieke Powerhouse-closure is:

`protected merge/main → exact productie/provider side effect → actuele readback → outcome-truth → Brain learning → skill/agent/chat projection → ledger/docs → System Map → read-after-write`.

## Wat is nu geborgd

- actuele productie-identiteit wordt expliciet vastgelegd;
- exact deploy-bewijs blijft gescheiden van functioneel bewijs;
- pricing, NL↔EN, social, e-mail, connectors en andere subketens behouden elk hun eigen evidence-gate;
- toekomstige chats en agents erven de writeback-verplichting automatisch;
- "live" mag niet worden gebruikt als shortcut voor "alles werkt".
