# Powerhouse Autonomous Sales Asset Execution v1 — 2026-09-28

Powerhouse must execute the commercial action it chooses. Generating advice or a draft is not completion.

The canonical behavior is now: decide -> create final copy/asset -> execute provider action -> provider acknowledgement/readback -> outcome -> learning.

For e-mail, the existing autonomous outreach runtime now materializes PDF-class Give/Get assets before sending. The PDF is created through the approved text-to-PDF capability and attached to the same Gmail send. PDF defaults include board one-pagers, evidence teardowns, lost-knowledge cases, friction business cases, mini benchmarks and peer benchmarks.

Posts and public comments remain owned by the canonical social/LinkedIn executors, which generate final content and publish rather than returning suggestions. A future verified DM capability may be used directly; until then, a DM choice must fall back to the highest-ranked executable channel instead of becoming a blocker.

Truth controls remain unchanged: no invented evidence, ROI, benchmark value, scarcity, urgency or social proof.
