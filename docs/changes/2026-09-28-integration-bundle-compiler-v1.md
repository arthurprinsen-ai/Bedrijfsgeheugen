# Integration Bundle Compiler v1

## Doel

Powerhouse had already centralized merge authority and terminal writer leases, but candidate metadata, risk routing, closure evidence and writer intent were still assembled by separate scripts and workflow steps.

The Integration Bundle Compiler makes that one deterministic preflight product.

## Bundle contents

One immutable candidate scope compiles to:
- exact base/head identity;
- canonical PR contract;
- R0-R4 adaptive risk;
- affected capabilities and test impact;
- closure materiality and required artifacts;
- exactly one writer intent bound to the obligation and exact head;
- deterministic bundle hash.

## Delivery effect

Required test now compiles the bundle before expensive work. Missing closure artifacts fail before dependency installation and heavy regression suites. The existing Repository Writer, Unified Brain Delivery and terminal writer lease remain mutation authorities; the compiler creates no second writer and performs no production mutation.

## Safety

Unknown executable paths remain R3 fail-closed. Hot paths can only escalate risk. Security, CodeQL, protected merge, provider readback and exact-head guarantees remain unchanged.
