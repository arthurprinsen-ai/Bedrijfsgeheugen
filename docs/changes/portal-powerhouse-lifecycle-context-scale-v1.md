# Portal + Powerhouse lifecycle context and Scale

Portal V2 already had the underlying building blocks: Strategy DNA, strategic models, business case, Impact Engine, Scenario Simulator, Capability Graph, decisions/actions, outcomes/evidence, Due Diligence, Exit and portfolio modelling. Scale also already had the commercial runtime envelope for 15 sources, hourly refresh, forecasting, scenario analysis, approval-required automation, audit trail and 120 minutes senior advisory per month.

This change closes the missing semantic layer.

## Canonical lifecycle contexts

Powerhouse and Portal V2 now understand the same six contexts:

- growth & professionalisation;
- loss & recovery;
- acute continuity pressure;
- buy-side M&A;
- sell-side / exit;
- investor / portfolio.

Each context maps to relevant decision questions, analytical models and portal destinations. Portal pages show connected source/action/outcome/risk counts from real state and fail open visually but fail closed on claims: if the lifecycle state is not explicitly or evidentially known, growth is only a navigation default and is labelled unproven.

## Scale

Scale uses the same core intelligence surfaces as the other paid plans. It is not a reduced-model edition. Its operating envelope remains:

- up to 15 connected sources;
- hourly refresh;
- forecasting and scenarios;
- actions with human approval;
- audit trail;
- 120 minutes senior advisory per month.

Control, Scale and Enterprise differ in scale, freshness, automation, governance and advisory capacity, not in model quality.
