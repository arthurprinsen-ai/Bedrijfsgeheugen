# Gemiste publicaties worden bij elke run met eigenaar gemeld

Datum: 6 november 2026
Obligation: `missed-publication-deadline-20261106-v1`

Een kanaal dat na de deadline niet gepubliceerd is, staat nu zichtbaar in de uitkomst van de orchestrator, met de naam van de eigenaar.
