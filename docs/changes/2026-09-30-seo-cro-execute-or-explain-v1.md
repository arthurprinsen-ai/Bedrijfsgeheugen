# SEO/CRO execute-or-explain contract — 2026-09-30

Fingerprint: `seo-cro-execute-or-explain-v1`.

Every material daily SEO/CRO opportunity must end in the same cycle as either:

- `EXECUTED`: a safe bounded reversible evidence-gated change is implemented through protected delivery and production readback; or
- `REJECTED_WITH_EVIDENCE`: no write is justified, with a canonical reason code, the exact evidence inspected, the missing/conflicting evidence and the condition that would make it executable later.

A recommendation-only operator response is not a valid terminal state.

Transient CI/tool/deploy problems are recovery work, not reasons to stop or downgrade execution into advice.
