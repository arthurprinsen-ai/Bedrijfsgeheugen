# Personal LinkedIn founder-story editorial recovery

The canonical daily personal LinkedIn generation repeatedly produced drafts outside the mandatory word count or containing internal operational terminology. The original policy correctly refused publication; this made the channel unreliable.

The fix allows one additional AI editing pass using only the same verified source. The result must independently satisfy the same exact editorial and personal truth gates before it becomes eligible. If it fails again, the original rejection remains, and per-channel cooldown lets unrelated publication lanes progress.

This adds no second publisher, no new sending path, no hidden approval, and no loosened wording rules. Tests cover the bounded revision and final veto. Production proof and provider publication IDs must be verified separately. P0 #4198 remains open.
