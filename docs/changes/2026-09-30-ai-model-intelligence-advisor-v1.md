# AI Model Intelligence & Advisor v1

Date: 2026-09-30  
Fingerprint: `powerhouse|ai-model-intelligence|goal-cost-governance-sovereignty|v1`

## Outcome
Built a value-first public AI model decision surface that compares model families at model level, estimates workload cost, filters on deployment/governance constraints and routes commercial intent into the existing Powerhouse lead/outcome lineage.

## Scope
- canonical normalized model catalog across OpenAI, Anthropic, Google, Mistral AI, xAI, DeepSeek, Cohere, Meta/Llama and Qwen;
- model-level capabilities, context, status, token/unit pricing, deployment options and official source;
- user-goal parser and explainable model scoring;
- volume/token workload calculator;
- hard filters for EU inference, self-hosting, open weights and active-production lifecycle;
- explicit data-governance/sovereignty model: storage, inference, jurisdiction, retention/training, subprocessors, network/keys, deployment control and lifecycle;
- multi-model routing recommendation;
- ungated first recommendation followed by optional lead capture;
- lead capture reuses `captureCommercialLead`, therefore qualified lead and downstream outcome learning stay in the existing commercial spine;
- SEO canonical route `https://www.bedrijfsgeheugen.nl/ai-modelwijzer`; sitemap generation discovers the new HTML route automatically.

## Guardrails
No universal model winner, no residency inference from provider nationality, no fabricated unknowns, no thin programmatic doorway pages, no second CRM/model-outcome store and no lead gate before value.

## Delivery state
Candidate implementation is complete in protected delivery lineage. LIVE may only be recorded after required tests, protected merge, exact-main production deployment and functional public readback.
