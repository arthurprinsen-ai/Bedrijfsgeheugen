# Diversify Mira's existing source radar without extra searches

A dated source is not a new story if its topic family was already used. The canonical Mira radar previously repeated eight identical daily search terms and therefore returned the same recent entrepreneur stories even after precise topic and source deduplication.

The existing daily eight-query budget now rotates deterministically through twelve approved entrepreneur problem categories using the Europe/Amsterdam business date. Search freshness, verified provider publication date, original source and topic uniqueness, editorial quality, exact video identity and authenticated Instagram publishing are unchanged.

This code change is not a new Reel. Protected merge, Supabase production source parity and a separate provider-verified Reel are required before any publication claim.
