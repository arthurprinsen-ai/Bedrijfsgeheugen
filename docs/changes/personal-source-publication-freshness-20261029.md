# Personal LinkedIn source recovery cannot silently choose old news

The existing fallback that finds a public news theme for a personal LinkedIn post lacked a source publication-date gate. This allowed an undated record to appear as fresh in the canonical recommendation table. The existing function now requires an independently recorded, explicitly confirmed publication date no older than 45 days. It still rejects already-used source URLs, cannot claim that the founder experienced an external article personally, and leaves the original semantic story-family duplicate gate in place. If no dated independent source exists, recovery must obtain new evidence rather than mark the publication complete. This is a targeted repair to the same source owner, not a second publisher.
