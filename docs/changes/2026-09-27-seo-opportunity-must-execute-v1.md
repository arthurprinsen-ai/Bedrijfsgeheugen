# SEO opportunities must execute — 2026-09-27

Fingerprint: `seo-opportunity-must-execute-v1`.

## Problem

A ranked SEO opportunity list is not useful as a terminal product when Powerhouse can safely perform the justified work itself. Advice-only output shifts execution back to the operator and breaks the SEO → lead → order → revenue loop.

## Permanent rule

Every commercially relevant daily SEO opportunity must terminate in the same canonical lineage as either **EXECUTED** or **REJECTED_WITH_EVIDENCE**. Existing intent owners are improved first. New blogs or landing pages are allowed only for an evidenced distinct intent gap.

An executed change follows candidate PR → required gates → protected merge → exact-main production identity → public readback. LIVE is forbidden before that proof.

Where useful, the executed asset is distributed through the canonical Bedrijfsgeheugen company channels without duplicate content or intent. Personal LinkedIn is not a company-content distribution target.

The operator receives an execution/impact log: work executed, evidence-based rejections, delivery/readback state, distribution state, and measured query → CTA → Frisse blik/scan → lead → offer → order → realized revenue outcomes. Advice is reserved for genuine human decisions.
