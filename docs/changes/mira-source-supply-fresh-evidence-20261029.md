# Improve Mira's source selection without weakening evidence requirements

The existing Mira research job was not finding enough distinct, verifiably recent entrepreneur problems for each day's original Reel. Instead of publishing stale or repeated material, this change concentrates part of the existing search budget on two concrete small-business frustrations: unpaid invoices and late billing. It also recognizes additional precise wording for overdue payments, mapped to the approved receivables problem library.

There are still eight searches, the original daily cron, one media router, strict source publication-date checks and unchanged source-deduplication windows. No copy or image is published by this patch. Passing GitHub checks is not proof of a new Reel: release also requires a real newly selected dated source, the approved reference-consistent video and official Instagram provider ID/readback. Internal operational incident records are kept outside public release artifacts.
