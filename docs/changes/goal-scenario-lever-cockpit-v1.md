# Goal scenario lever cockpit

The Goal Cockpit now connects measurable goals to explicit what-if levers.

## Product behavior
- baseline expected outcome comes from the evidence-aware forecast when available, otherwise the current value;
- each goal exposes context-relevant levers;
- the entrepreneur can enter an expected effect per lever;
- Portal shows baseline → scenario → target and the reduction of the target gap;
- quantified levers are ranked by scenario effect;
- next-best actions route into existing Portal modules such as Impact Engine, value & financing, Data & AI, Due Diligence and Exit.

## Truth contract
A forecast and a scenario are different things. Forecasts remain based on observed historical data. Lever effects are what-if assumptions unless source evidence is explicitly attached. Powerhouse never converts an unbacked scenario assumption into a probability or factual expected outcome.
