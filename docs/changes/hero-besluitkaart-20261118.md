# Hero: besluitkaart in plaats van poort en stockfilmpje

Het hero-beeld (boogvorm met mistig wolkenkrabbervideo) paste niet bij de belofte: geen mensen, geen link met besluiten, mist suggereert onduidelijkheid. Vervangen door een herkenbaar voorbeeld-besluit (vraag, waarom nu, bron, eigenaar, vastgelegd), duidelijk gelabeld als voorbeeld. Geen schaarste, geen teller. De WhatsApp-knop verschijnt pas na een schermhoogte scrollen en dekt de hoofdknop niet meer af. EN-tekst via de bestaande ritueelwoordenlijst. Cache-bust CSS `?v=20261118k`, JS `?v=20261118j`. Op schermen onder 1100 px staat de kaart onder de hero-inhoud, zodat de kop niet achter de onderbalk valt.
Niet bewezen: live-readback tot na merge; effect op kliks (meten via bg_interacties, vergelijk met de week ervoor). Voorbeeldnamen zijn fictief en als voorbeeld gelabeld.
