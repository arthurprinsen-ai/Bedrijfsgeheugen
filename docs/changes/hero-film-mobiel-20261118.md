# Hero-film zichtbaar op mobiel

Op mobiel stond het filmpje onder de uitleg, buiten het eerste scherm (zichtbaar in een schermafbeelding van Arthur). Op schermen tot 1100 px staat het nu in de hero-kolom direct onder de hoofdknop; de kop en knop blijven op hun plek (kop 152 px, knop 336 px op 390x844), film 401–656 px. Het besluitkaartje is op mobiel kleiner zodat het gezicht vrij blijft. Desktop ongewijzigd. Cache-bust CSS `?v=20261118m`, JS `?v=20261118l`.
Niet bewezen: live-readback tot na merge; effect op kliks (meten via bg_interacties).
