# Bedrijfsgeheugen Brain Foundation Acceptance

The foundation is accepted only when one trace proves: `Evidence -> Signal/Opportunity -> Decision -> Mission -> Outcome -> Pattern -> changed next Decision` with one trace lineage, explicit evidence authority, mission baseline/measurement/protected metrics/budget/rollback, and no hard-boundary bypass.

Required regression suites cover component registry, universal contracts, priority/portfolio policy, context authority/minimization, Creative/Prompt Cortex, data quality/quarantine, Make adapter authority, shadow decisions, calibration, autonomy, production constitution, economics, observability and end-to-end learning.

A passing repository test is not production acceptance by itself. Production remains governed by exact-candidate verification, preview/canary, protected metrics and BG169 production authority. Any production regression rolls back to last-known-good and keeps the candidate in RECOVERING.
