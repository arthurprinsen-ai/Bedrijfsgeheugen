# Repository writer delivery — BRAIN-DELIVERY-v2

All automated repository writers are candidate producers, never production authorities.

Flow: writer renders deterministic change → candidate commit/branch → PR → lane/contract/security/cost/preview gates → BG169 guarded exact-head promotion → Netlify exact production verification → public/outcome proof → BG168/BG166 learning → BG167 current-state refresh.

Forbidden: direct push to `main`, self-merge, force-push promotion, deployment of an untested identity, or marking production green from writer success alone.
