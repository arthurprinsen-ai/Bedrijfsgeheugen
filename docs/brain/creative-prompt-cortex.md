# Creative Intelligence & Prompt Cortex

This cortex connects the creative intelligence that already exists in Powerhouse instead of rebuilding it.

`Business/Market/Sales Evidence -> Creative Strategy -> Narrative DNA -> Format Brain -> Prompt Compiler -> Model/Tool Adapter -> Asset -> Outcome -> Component Learning`

Existing responsibilities are authoritative:

- **BG09**: Creative Strategy, Narrative Brain, channel/format allocation and candidate prediction. It already chooses Text/Image/Video and produces channel-specific variants plus narrative episode, arc, role, core story, brand signature, coherence and next experiment.
- **BG14**: observed Creative Learning. It classifies text/hook/CTA/video types and calibrates narrative, soap, commercial and downstream performance against actual outcomes.
- **BG24**: specialist Video/Prompt Brain for the Mira Instagram serial format. It owns scene beats, opening mechanism, emotion, spoken lines, cliffhanger, continuity, supporting character, conflict, location, running gag, camera and audio production intent.
- **BG25**: carousel/visual production actuator.
- **BG180**: scene-level Instagram outcome and learning feedback.
- **PH Agent 10 / PH Agent 15**: calendar execution and post-quality guarding.

The Brain adds a shared `CreativeIntent` contract above these components and a `PromptCompilation` contract below it. Prompt compilation only translates approved creative intent into the exact syntax/constraints of the chosen generation model; a generated prompt is not evidence and cannot overwrite business truth.

Learning is component-level and contextual: `audience x problem x format x text type x hook x emotion x narrative x character x scene x camera x audio x CTA x channel x timing -> business outcome`. A winner teaches a mechanism, not a template. A successful Mira opening may inform another video experiment without copying the scene. Sales objections may become new creative/SEO/product signals and creative outcomes may update sales positioning.
