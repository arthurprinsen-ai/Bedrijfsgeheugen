# Make adapters into the Bedrijfsgeheugen Brain

Adapters normalize existing scenario outputs into Brain contracts without changing stable specialist responsibilities.

Control-plane authority is fixed: BG166 persists append-only events/learning; BG167 projects current shared context; BG168 routes outcomes and pattern candidates; BG156 orchestrates Missions; BG169 is the sole production-promotion authority. BG157 owns security gates and BG162 owns cost/quality gates.

Creative flow reuses BG09 -> CreativeIntent, BG24 -> PromptCompilation, BG25 -> visual/carousel Outcome, BG14/BG180 -> Pattern/Signal learning. Research, SEO, commercial, product and social scenarios emit Signals/Evidence/Outcomes and do not independently redefine company-wide priority.

Adapters must preserve `trace_id`, `correlation_id`, parent lineage and deterministic idempotency for side effects. A scenario that writes CurrentState needs explicit projection/production authority. A scenario that writes Outcome must carry trace lineage back to its Decision/Mission.
