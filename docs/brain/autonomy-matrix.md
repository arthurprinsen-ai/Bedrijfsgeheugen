# Brain Autonomy Matrix

A0/A1 covers observation and safe internal/reversible actions such as research, analysis, validation, dedupe, cache, enrichment and test generation. A2 covers reversible business actions only when policy, contact pressure, measurement, rollback and protected metrics are satisfied. A3 covers production changes exclusively through the production constitution.

The immutable hard-boundary set is credentials/secrets/permissions, weakening security, destructive or irreversible data mutation, paid-resource increase, and legal/financial commitments. Learned weights cannot change this set.

Every autonomous action must remain traceable to Decision/Mission and write an Outcome. Production execution additionally requires baseline, regression, security, cost/performance, exact candidate identity, preview/canary, rollback, protected metrics and exact production verification.
