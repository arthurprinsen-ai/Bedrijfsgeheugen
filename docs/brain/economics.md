# Brain Economics

The Brain maximizes incremental business value per resource while protecting quality, security and reliability; it does not blindly minimize spend.

Compute order is `CACHE -> DETERMINISTIC -> DATA_QUERY -> STATISTICS -> SMALL_MODEL -> LARGE_MODEL -> MULTI_AGENT`. Every Mission has bounded Make credits, external calls, AI steps, runtime and two identical retries maximum. Higher compute is justified only by expected value, uncertainty and complexity.

Measure cost per verified signal, opportunity, qualified lead, meeting, useful asset, production improvement, useful learning and incremental value. Cost anomalies include credits/run spikes and retry storms. Existing Cost Snapshot, Cost Optimizer, Runtime Guard and Adaptive Cost/Quality Governor remain the live economic sensors/governors.
