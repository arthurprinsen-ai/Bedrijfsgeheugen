# Chat learning — AI Model Advisor v1 — 2026-09-30

The reusable design lesson is that an AI model comparison asset should not be a benchmark leaderboard. The correct decision unit is **user goal + workload + hard governance constraints + cost per task + explainable alternatives**.

Permanent prevention:
1. Never collapse storage residency and inference residency.
2. Never call EU residency full sovereignty.
3. Never fill unknown provider governance properties by assumption.
4. Never select a universal winner independent of workload.
5. Never optimize the acquisition page to raw traffic; preserve qualified lead → order → realized revenue measurement.
6. Do not create a separate lead/outcome store when the Powerhouse commercial spine already exists.
