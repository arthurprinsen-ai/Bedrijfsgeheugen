# Development ledger — Contextual Intelligence Visibility Governance v1

Date: 2026-09-28
Obligation: BG-20260928-CONTEXTUAL-INTELLIGENCE-VISIBILITY-GOVERNANCE-V1

## Why

Contextual foresight proved a broader rule: intelligence has little operational value when it lives only in Brain/Supabase or on an isolated intelligence page.

## Governance change

The rule is now inherited by:
- Powerhouse Company Intelligence OS;
- Powerhouse System Map Governance;
- all future material intelligence capabilities through System Map governance.

## Invariant

If intelligence materially changes a user's decision, the same delivery lineage must contain a relevant Portal V2 projection, evidence/uncertainty behavior, regression coverage and System Map relationship.

## Anti-patterns prevented

- backend-only AI capabilities;
- generic AI-insight dumping pages;
- duplicated forecast/benchmark logic in Portal V2;
- hidden uncertainty;
- intelligence without an action context.

## Existing implementation proving the pattern

Contextual Foresight Portal v1 is the first implementation of this governance pattern.
