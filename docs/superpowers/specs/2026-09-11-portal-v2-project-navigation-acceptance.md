# Portal V2 Project Navigation Acceptance

Approved design requirements:

- both navigation levels are required;
- mobile keeps one global bottom navigation: Overzicht / Project / Data & AI / Taken / Meer;
- Project opens one context layer with Overzicht / Commercieel / Bouwen & koppelen / Projectinformatie / Samenwerken;
- desktop shows both the project section and its groups;
- project functionality is grouped around selling, building software, creating connections/integrations, executing work and project administration;
- existing V2 routes/state remain canonical.
