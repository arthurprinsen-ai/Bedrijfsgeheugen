# V18 test route policy

Approved 2026-08-29.

1. If an accepted V18 link already has a V18 test page, that V18 page is leading on test.
2. If a V18 link has no V18 page but an existing production page exists, preserve that production page on the test branch.
3. If neither exists, create the missing page in the V18 visual and information architecture.
4. Preserve the production Blog and other production-only pages unless explicitly superseded by accepted V18 evidence.
5. Every visible desktop/mobile/footer/Meer link must resolve to a real page; no dead links or 404s may be accepted as green.
6. Production remains unchanged until explicit visual/business approval.
