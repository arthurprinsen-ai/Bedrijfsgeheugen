# Growth Intelligence V2 Design

Goal: complete the existing Growth Revenue OS without a parallel data system. The daily runtime persists an evidence-linked market/company graph, company and white-space intelligence, prior predictions, due calibration, stale-knowledge decay, offer learning and deduplicated realized-revenue attribution.

Canonical storage: `brain_records` stores entity/relation/current-state graph records; `revenue_learning_decisions` prior predictions; `revenue_learning_obligations` evaluation duties; `revenue_learning_evidence` observed outcomes; `revenue_learning_applications` prediction-versus-outcome verification; `revenue_learnings` confidence/lifecycle. Existing opportunities, connections, engagement, offers, external signals and outcomes stay source truth.

Runtime: ingest -> company/market profiles -> persist graph -> latent demand -> 75/25 exploit/explore -> prior prediction -> execute -> due 24h/72h/168h evaluation -> Brier/error/counterfactual -> learning decay/lifecycle -> deduplicated attribution -> scorecard -> next run.

Company facts are OBSERVED only with source evidence. Technology/hiring/capability clues are INFERRED and source-linked. Market/competitor supply uses observed external domain/source coverage; no competitor is invented. Missing baseline/outcome remains INSUFFICIENT_EVIDENCE. Signed offer value is order value, never realized revenue.

Success requires exact-SHA CI, merge, production deploy/readback, Brain/Supabase runtime readback, and keeping `growth-calibration-bootstrap-2026-09-13` open until its real due time and evidence-supported evaluation.
