# Powerhouse SEO Growth Engine

Status: canonical
Updated: 2026-09-29
Owner: Powerhouse Growth Intelligence

## Objective
Organic traffic is not the goal. Qualified conversations, scans, builds and subscriptions are the goal. Every SEO decision therefore follows:
search intent -> page promise -> proof -> low-friction CTA -> conversion -> revenue -> learning.

## Non-negotiable rules
1. One primary search intent per money page. Supporting pages must add distinct user value.
2. Never generate doorway, near-duplicate or scaled thin pages.
3. Every commercial page must answer: problem, outcome, proof, price/effort expectation, risk, next step.
4. Use buyer language in title, H1, first paragraph, internal anchors and CTA.
5. Search snippets must be unique and specific; no generic meta descriptions.
6. Structured data must match visible current content and current products/prices.
7. Internal links point from informational pages to the most relevant money page, not blindly to home.
8. Every CTA is instrumented by page + intent + CTA type.
9. Every meaningful experiment has hypothesis, variant, metric, sample window and outcome memory.
10. Organic changes are judged on qualified leads and revenue, not impressions alone.

## Models used
- Search intent mapping: informational, commercial investigation, transactional, navigational.
- JTBD: trigger -> struggle -> desired progress -> proof -> next step.
- PAS: problem -> agitation -> solution.
- AIDA: attention -> interest -> desire -> action.
- 4P: promise -> picture -> proof -> push.
- Risk reversal: reduce uncertainty before asking for commitment.
- Message match: SERP promise, H1 and CTA describe the same job.
- Information scent: descriptive anchors and predictable page hierarchy.
- Topic clusters / hub-spoke architecture.
- E-E-A-T evidence: author, first-hand implementation evidence, sources, review dates.
- Conversion hierarchy: primary CTA, secondary CTA, exit CTA.
- Objection handling: price, time, switching risk, dependency, security, ownership.
- Outcome memory: source, intervention, conversion, revenue result, confidence.

## Daily autonomous loop
1. Read production pages, sitemap, robots, llms.txt and current pricing.
2. Check current rankings/volumes/SERP features for priority commercial queries.
3. Detect content decay, cannibalisation, stale claims, broken CTAs, schema drift and internal-link gaps.
4. Rank opportunities by expected commercial value = intent x volume x feasibility x conversion impact.
5. Apply at most three high-confidence reversible changes per cycle.
6. Never publish a new SEO page unless it adds materially unique usefulness.
7. Validate HTML, canonical, title, H1, schema, crawlability and Lighthouse.
8. Merge only after checks; verify the production URL after deployment.
9. Record hypothesis, exact change, evidence and result in Powerhouse outcome memory.
10. Feed winning patterns into future page generation and losing patterns into prevention rules.

## Conversion standard for money pages
Above the fold should contain:
- exact problem/outcome wording;
- who it is for;
- concrete expected scope/time/price range where known;
- primary CTA with low friction;
- secondary self-service CTA;
- risk-reversal sentence;
- proof or implementation evidence.

Mid-page:
- examples/use cases;
- process;
- transparent boundaries ("what we do not do");
- proof/cases;
- FAQ matching buying objections;
- contextual internal links.

End-page:
- one decisive CTA;
- alternative lower-commitment path;
- no competing navigation-heavy call to action.

## Guardrail
Google Search Essentials and spam policies are authoritative. Powerhouse must not use keyword stuffing, cloaking, doorway pages, link schemes or scaled low-value AI content. Automation is allowed only when user value and factual quality remain higher after the change.
