# Powerhouse Self-Improvement Layer

Fingerprint: `powerhouse|self-improvement|evidence-eval-compare-promote-measure-learn|v1`

## North Star

**Powerhouse must function measurably better tomorrow than today without degrading reliability, safety or code quality.**

The defensible advantage is not one foundation model. It is the compounding combination of Company Graph, System of Context, verified Outcome Memory, workflow intelligence, evaluations, procedural learning, connectors, execution evidence and engineering learning.

## Canonical loop

`Company Graph → Context → Intelligence → Agents → Actions → Outcomes → Learning → Better code/models/processes → Company Graph`

The self-improvement control loop is:

`Observe → Detect → Hypothesize → Build → Test → Evaluate → Compare → Promote → Measure → Learn`

## What was added

- **Agent Objective Registry**: every major agent has one measurable primary outcome and explicit guardrails.
- **Evaluation + Promotion Gate**: candidate changes must prove complete evidence, quality, security, regression safety, bounded cost/latency and measurable business or quality improvement.
- **Provider-neutral Model Router**: model selection is based on capability, privacy, quality, reliability, cost and latency rather than provider identity.
- **Architecture Guardian**: detects architecture degradation through dependency cycles, coupling, duplication, security findings, performance regressions and schema drift.
- **Learning Compiler**: converts verified outcomes/incidents into regression requirements, skill projection, documentation, System Map writeback and bounded optimization candidates.
- **Daily Improvement Score**: combines company learning, agent learning, engineering learning, architecture health, business outcomes, reliability and evidence completeness.

## Safety boundary

Self-improvement is autonomous in observation, diagnosis, candidate generation and evaluation. It is **not** uncontrolled self-modification.

A learning can create a candidate, test, policy proposal or code proposal. Promotion still reuses the existing protected Powerhouse delivery authority. Unknown evidence is never green.

Hard rules:

1. No learning without evidence.
2. No change without evaluation.
3. No deployment without regression proof.
4. No intelligence without measurable outcome.
5. No uncontrolled production self-rewrite.
6. No parallel learning store or delivery authority.
