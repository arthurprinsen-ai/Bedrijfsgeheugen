# Regulatory source organism v1

Official regulatory sources are observations, not interpretations.

1. The watcher reads only configured authoritative sources and records source URL, response metadata and cryptographic hashes.
2. A first observation establishes a baseline. A later hash change creates a regulatory review obligation; it does not claim that a legal requirement changed.
3. Raw changed response bytes are retained as run evidence and must be persisted through the canonical source-observation intake before a regulatory interpretation can become current.
4. Framework changes enter the same Powerhouse organism graph used by Portal V2.
5. Controls verified before the observed regulatory change become evidence-missing/review-required. They can become VERIFIED again only after re-evaluation and new evidence.
6. Regulatory interpretation remains versioned separately from immutable source observations.

Authoritative configured sources currently cover EU AI Act, EU NIS2, Dutch Cbw/NIS2 information and GDPR.
