# Learning — Contextual Compound Intelligence Portal v1

## Gap
Forecasts and prediction-quality evidence were visible, but the portal did not show whether Powerhouse itself was measurably learning and improving.

## Resolution
The contextual foresight read model now includes the canonical `powerhouse_self_improvement_control_v1` state and renders verified outcomes, learning-company count, candidate measurement coverage, compiler readiness, evidence/regression debt, model/guardrail issues and the full Observe → Learn loop.

## Prevention
A self-improving capability is not considered user-visible until the portal exposes its evidence, uncertainty and promotion guardrails in decision context. Code changes or model novelty are never treated as proof of improvement.
