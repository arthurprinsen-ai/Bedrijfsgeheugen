# Learning — Contextual Compound Intelligence Portal v1

Forecasts were visible, but the portal did not show whether Powerhouse itself was measurably learning. The contextual foresight layer now projects the canonical self-improvement control state: verified outcomes, learning companies, candidate measurement coverage, compiler readiness, evidence/regression debt, model/guardrail issues and the Observe → Learn loop.

Prevention: code or model novelty is never proof of improvement; visible improvement claims require runtime evidence and promotion guardrails.
