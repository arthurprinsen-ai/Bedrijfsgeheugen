# Powerhouse Live System Map — één pagina voor het hele systeem

De bestaande Notion System Map blijft de menselijke architectuur-authority. Powerhouse Control Center krijgt daar nu een levende operationele projectie bovenop.

De pagina laat in één scherm zien:

- de vier authorities: GitHub, Netlify, Supabase en Notion;
- Portal V2 en externe providers als surfaces/providers;
- de volledige intelligentieketen van evidence en knowledge tot prediction, decision, agents, delivery, learning, governance en resource intelligence;
- hoe gegevens en bewijs tussen de authorities lopen;
- alle geregistreerde GitHub-workflows, Netlify-functions, Supabase Edge Functions, Powerhouse skills en agent-fabric modules;
- live Supabase tabellen, views, databasefuncties en actieve cron-jobs;
- alle runtime-actors die in de canonieke observability-events voorkomen.

De kaart is geen los dashboard en geen tweede bron van waarheid. GitHub-inventaris wordt fail-closed tegen de repository gecontroleerd; Supabase-inventaris wordt live uit de databasecatalogus gelezen; Notion blijft de menselijke System Map authority; runtime actors komen uit dezelfde evidence-lus als het Control Center.

## Universeel agentcontract

Iedere huidige en toekomstige chat/agent/workflow/capability moet:

1. vóór structureel werk de bestaande System Map lezen;
2. bestaande capabilities hergebruiken;
3. bij create/rename/retire/rewire identiteit, owner, inputs, outputs en relaties vastleggen;
4. runtime-evidence met actor-identiteit schrijven;
5. System Map manifest + menselijke System Map in dezelfde lineage actualiseren;
6. read-after-write bewijzen voordat de structurele verandering terminal is.

Ontbrekende registratie is `SYSTEM_MAP_WRITEBACK_INCOMPLETE`.
