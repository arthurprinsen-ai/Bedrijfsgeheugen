# Learning — Predictive intelligence needs forecast resolution

Powerhouse already generated forecasts, but predictive intelligence compounds only when predictions are later resolved against reality. The system must optimize for calibrated accuracy rather than forecast volume.

Canonical loop:

`Signals → Forecast → Scenarios → Outcome → Resolution → Calibration → Challenger → Better Forecast`

Unresolved due forecasts are learning debt. Probability quality is measured with Brier score and calibration error; timing quality with mean absolute error. Improvements to probability mapping, horizon estimation or forecast method must prove themselves through historical backtesting and controlled shadow/canary comparison before promotion.

This learning is shared with the Self-Improvement Layer so degradation in predictive quality becomes a bounded improvement obligation rather than an uncontrolled production rewrite.
